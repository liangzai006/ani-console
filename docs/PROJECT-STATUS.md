# Console 当前状态

> 本文件是项目当前状态与简短开发记录的唯一真来源，仅保留仍有效的口径、缺口和近期里程碑。

## 当前口径

- 项目：独立 ANI Console 前端；仓库根目录已代表 Console 范围，路由和文件直接按业务领域或资源命名。
- 后端：独立 ANI 仓库；接口契约与行为以 Core OpenAPI、实现代码和 GitNexus 索引 `ANI` 为准。
- API：`/api/v1`，统一通过 `src/api/client.ts` 的 `coreApi` 调用。
- 产品原型：GitNexus 索引 `产品原型-8.25`；页面信息架构与交互布局以该版本为准。
- UI：使用 Arco Design React 和 Arco Token，Tailwind 仅负责布局；沿用现有顶部一级导航及侧栏层级。
- 验证：默认运行 TypeScript typecheck、`git diff --check` 与 GitNexus 变更检测；不运行 `pnpm run verify`、production build 或干预用户的 `pnpm dev`。
- 测试：快速迭代阶段不保留自动化测试资产，页面与交互由用户手动验证。

## 模块状态

- 计算：资源概览、云主机、容器、GPU 容器、Sandbox、GPU 算力管理和 K8s 集群。
- AI：模型、推理服务、知识库、向量存储和 Registry；模型仓库接口未就绪时保持明确空态。
- 存储：块、文件、对象和向量存储的列表、详情及 ANI 已开放的生命周期操作。
- 网络：VPC、子网、安全组、路由和负载均衡的列表、创建与详情。
- 基础能力：租户账密登录、统一列表与详情骨架、游标分页、状态提示、幂等写请求及操作详情。

## 当前缺口

- Bare Metal、Notifications、Audit 仍为占位页面，等待后端契约。
- OIDC 登录入口暂时隐藏；当前使用租户账密登录。
- 文件存储权限、部分监控/事件等 ANI 未开放能力保持空态，不提供虚假操作。
- 浏览器自动化回归暂时移除。

## 当前工作区变更（2026-08-28）

- 子网列表的 VPC 列改用 Arco Design `Link` 展示，并保留站内客户端路由跳转。
- GPU 容器迁至独立 `/gpu-instances` 路由和领域组件；创建流程采用独立五步 Modal，并修复跨步骤字段、规格映射和弹窗布局。
- GPU 容器列表补齐状态原因、镜像省略展示及完整生命周期行操作，移除无对应批量能力的复选框，并按实例状态控制操作可用性。
- 新增独立 GPU 容器详情页：沿用公共详情骨架，按原型组织发布、存储、配置、网络、监控、日志、事件、终端和操作历史；通用实例详情自动转入该页面。
- 存储挂载按 ANI 契约区分云盘与 NFS，资源由接口异步选择并过滤不可用项；提交前校验 NFS 挂载目标，敏感配置采用最小披露。
- 同步实例详情契约字段和 GPU 生命周期操作类型；统一状态原因读取 `reason`，列表与详情均展示真实镜像、计算、网络、访问和挂载信息。
- 新增“我的资源概览”作为计算默认入口，并同步菜单、路由树、快捷入口和 Registry 跳转；缺少专用接口的数据保持缺失值或空态。
- 收敛公共组件导入与集中导出，清理列表错误通知的废弃重试入口；明确 Console 命名、契约来源和开发记录规则，并统一文本格式配置。
- GPU 容器实例详情取消定时轮询；加载失败时改用非阻断 Notification 提示并保留详情页骨架，不再被错误页覆盖。
- GPU 与通用实例的操作历史统一保留为详情页内按需加载的列表视图；移除行级“详情”入口、独立操作详情路由及通用实例独立操作历史页，同时取消 GPU 操作历史定时轮询。
- 统一页面查询失败体验：详情页使用非阻断 Notification 并保留已有数据或资源 ID 骨架，列表与 Tab 使用 Notification 和正常空态；登录、类型不匹配、表单、任务及流式连接错误保持原有语义展示。
- 移除全部 React Query `refetchInterval` / `refetchIntervalInBackground` 定时轮询及共享游标查询中的轮询配置入口；保留主动刷新、操作成功后的缓存失效刷新、按需查询和镜像上传流程内的就绪等待。
- 统一列表手动刷新反馈：19 处资源列表及详情内嵌列表改用查询中的 `isFetching` 展示表格加载态；K8s 集群刷新按钮同步展示刷新状态，多查询网络页面在关联数据刷新期间保持列表加载反馈。
- 验证：新增及修改的 GPU 页面已使用仓库内置 Prettier 格式化，定向 Oxlint 仅报告文件路由的既有 Fast Refresh 规则提醒，TypeScript typecheck 与 `git diff --check` 通过；GitNexus 全工作区变更风险为 MEDIUM，受影响流程来自同工作区此前的通用实例详情改动，页面与交互待用户手动验证。
- 本批详情、操作历史、错误提示、轮询及手动刷新反馈调整通过 TypeScript typecheck 与 `git diff --check`；GitNexus 全工作区汇总为 CRITICAL，覆盖 49 个变更文件与 91 条执行流程，并包含用户已有的子网页面变更及多项路由删除；共享游标查询轮询入口的定向影响为 CRITICAL，本次列表刷新反馈调整的定向影响均为 LOW，页面与交互需用户重点手动走查。
